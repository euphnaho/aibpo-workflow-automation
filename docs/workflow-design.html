04

Slackワークフロー設定手順

Slack Workflow Builder 側は手動設定。GASからは自動生成できない。

  1. ワークフロー作成
    「商談結果報告」という名前で新規作成する。
  2. リンクトリガーを設定
    入力変数 calendar_id company_name contact_name sales_rep を定義。GASが投稿するSlackメッセージのボタンURLにクエリパラメータとして埋め込み、営業担当の再入力を減らす。
  3. フォームステップ①を追加
    「案件化ステータス」を単一選択にする：案件化した / 進行中（未失注） / 失注した。
  4. If/Then で3方向に分岐
    案件化した→案件名・想定金額・対象業務領域・次回商談日。進行中→ネクストアクション・ネクストアクション日・案件化見込み度。失注した→失注区分・失注理由（マスター参照）・詳細メモ。
  5. 最終ステップに「Webリクエストを送信」を追加
    GAS Web App の /exec URLへPOST。認証用の共有シークレットはヘッダーではなくJSONボディに含める（GAS側でカスタムヘッダーが読めないため）。
05

導入マイルストーン（①〜⑨）

番号は次の「06 スケジュール」の日程表と共通。

  • ①既存の「初回商談一覧」生成スクリプトを調査する
  • ②初回商談一覧に紐付け用の4列を追加し、案件化中商談一覧・失注リストを新規作成する
  • ③①の調査結果をふまえ、カレンダーID列を既存処理に組み込む
  • ④Slack Botを作成し chat:write スコープを付与、対象チャンネルに招待する
  • ⑤Slack Workflow Builderで「商談結果報告」を設定する
  • ⑥gas/ 配下のコードをApps Scriptプロジェクトへ配置・スクリプトプロパティ設定・Web Appデプロイする
  • ⑦notifyCompletedFirstMeetings に時間主導トリガーを設定する
  • ⑧ダミーデータでE2Eテストする（実企業名は使わない）
  • ⑨チームへ共有・運用開始を案内する
